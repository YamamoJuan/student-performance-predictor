# Student Performance Predictor

An end-to-end machine learning project that predicts a student's final math performance class (Low / Medium / High) from study and lifestyle factors. Built with Python, Scikit-learn, and Streamlit.

## Problem Statement

Predict a student's final math performance class before the final grade is known, using only demographic, study, and lifestyle information available during the school year.

## Dataset

- **Source**: UCI Machine Learning Repository — Student Performance (ID 320)
- **File**: `student-mat.csv` (Mathematics course), 395 students, 33 attributes
- **License**: CC BY 4.0 — Cortez, P. (2008). https://doi.org/10.24432/C5TG7T
- **Target**: 3-class label derived from final grade `G3` (0-20):
  - **Low**: G3 <= 9
  - **Medium**: 10 <= G3 <= 13
  - **High**: G3 >= 14

## Features

The model uses 30 input features: demographic (school, sex, age, address, famsize, Pstatus), parental (Medu, Fedu, Mjob, Fjob), school/lifestyle (reason, guardian, traveltime, studytime, failures, schoolsup, famsup, paid, activities, nursery, higher, internet, romantic, famrel, freetime, goout, Dalc, Walc, health, absences).

**Data leakage note**: `G1` and `G2` (earlier period grades) are excluded because they are nearly direct proxies for the final grade `G3` and are unavailable at prediction time.

## ML Approach

1. **Data understanding & EDA** — notebook in `notebooks/student_performance_analysis.ipynb`
2. **Preprocessing** — ColumnTransformer with median imputation for numeric features, mode imputation + one-hot encoding for categorical features. Imputation is included even though the dataset has no missing values. Fitted only on the training split.
3. **Models trained** — Logistic Regression (with StandardScaler) and Random Forest
4. **Evaluation** — 80/20 stratified split, accuracy, precision, recall, F1-score, confusion matrix
5. **Selection** — final model chosen on F1-macro (better for imbalanced classes than raw accuracy)
6. **Serving** — trained pipeline saved with joblib and loaded by the Streamlit app

## Models Tested

| Model | Accuracy | F1-macro |
|-------|----------|----------|
| Logistic Regression | 0.481 | 0.481 |
| Random Forest | 0.494 | 0.484 |

**Selected**: Random Forest (higher F1-macro). The confusion matrix shows it is best at separating Medium and Low, though overall separation is modest — this is expected when G1/G2 are excluded.

## How to Run Locally

```bash
git clone <repo-url>
cd student-performance-predictor
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
python -m src.train             # trains and saves model.joblib
streamlit run app.py
```
